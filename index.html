ОПЕРАЦИОННАЯ ДЕЯТЕЛЬНОСТЬ

Инженер ИБ

Повседневная работа с уязвимостями, углубленный триаж, валидация исправления и устранение слепого шума:

  • Триаж находок с фиксацией доказательной базы (proof).
  • Инструментальная ре-верификация: закрытие только по повторному скану (machine_verified = true).
  • Patch Gaps: готовые консольные команды обновления дистрибутивов (Ubuntu USN / Debian Security).
  • Фильтрация невоспроизводимых CVE и подавление FP.

Архитектор ИБ / Enterprise

Картографирование ландшафта, контроль сегментации, интеграции и соответствие регуляторным нормам:

  • Инвентаризация периметра (EASM/CAASM), выявление Shadow IT.
  • Топология remote agents через NATS JetStream mTLS без входящих портов в сегментах.
  • Интеграция с CMDB, Active Directory, CI/CD и SIEM/SOAR.
  • Оценка соответствия: PCI DSS 4.0, CIS Controls v8, ISO 27001.

СТРАТЕГИЧЕСКОЕ УПРАВЛЕНИЕ

CISO / Руководство ИБ

Управление совокупным риском компании, соответствие стандартам и объективные метрики зрелости:

  • Дашборд Estate Risk по NIST SP 800-30 Rev. 1: двухосевой скоринг (вероятность vs ущерб).
  • Контроль эксплойтов в дикой природе (CISA KEV) и EPSS.
  • Контроль соблюдения SLA ремедиации и медианного MTTR.
  • Метрики Adoption и Noise: контроль качества работы команды.

Rust • BAS & Red Team

ASMODEUS

Adversary Emulation (BAS), Red Team Cyber Exercises & Chaos Engineering Engine на Rust (NIST CSF 2.0).

  • 8 сценариев MITRE ATT&CK (Ransomware, K8s Escape, C2, Exfiltration)
  • Инфраструктурный хаос (LATENCY_SPIKE, AGENT_CRASH, DNS_SINKHOLE_DROP)
  • Защитные барьеры: Blast Radius limit, Circuit Breaker, Auto-Rollback
  • Замер метрик Blue Team: MTTD, MTTR, Resilience Score

Rust • Kubernetes eBPF Security

FERRUM

Self-hosted Kubernetes enforcement plane на Rust. Admission + runtime enforcement, подписанные policy bundle, last-known-good вместо fail-open.

  • eBPF sys_enter tracepoint datapath (aya-ebpf)
  • Admission Webhook: fail-closed, hot-reload, LKG на диске
  • Ed25519 Signed Bundles: офлайн-выпуск PKI и валидация
  • Strict Boundary Gate: строгий контроль покрытия тестами
#Rust #Kubernetes #eBPF #Aya #Policy-Bundles

Python • EASM & RBVM Enterprise Wiki 🇷🇺

Shapoclyack

Self-hosted EASM, CAASM и Risk-Based Vulnerability Management платформа со встроенной Enterprise Wiki и механической верификацией.

  • Asset-Centric модель: сохранение контекста активов при смене IP/DHCP
  • Двухосевой риск по NIST SP 800-30 Rev. 1 (Likelihood vs Impact)
  • Механическая ре-верификация закрытия (machine_verified = true)
  • Vendor Advisory Matching (Patch Gaps для Ubuntu USN / Debian)
  • Enterprise Wiki: ролевые сценарии (Инженер, Архитектор, CISO) и регламенты SLA

Go • Scalable Network Sweep

Network Scan CLI (Octo-man)

Контейнеризованный конвейер пакетного сканирования масштабных сетей (CIDR + IP + FQDN).

  • Лестница зондирования (Probe Ladder): fping ICMP -> TCP SYN -> naabu
