APEX Platform · 8 Contract-Enforced Components · Open Source

Composable security engineering with
explicit ownership & versioned boundaries

APEX connects eight focused systems without collapsing them into one monolith: each service owns its domain, the Gateway stays an integration plane, APIs and events are versioned, and the architecture contract is enforced in CI. EvaCal, Metis and R-TrustTunnel remain useful standalone tools for colleagues outside the platform boundary.

ОПЕРАЦИОННАЯ ДЕЯТЕЛЬНОСТЬ

Инженер ИБ

Повседневная работа с уязвимостями, углубленный триаж, валидация исправления и устранение слепого шума:

  • Триаж находок с фиксацией доказательной базы (proof).
  • Инструментальная ре-верификация: закрытие только по повторному скану (machine_verified = true).
  • Patch Gaps: готовые консольные команды обновления дистрибутивов (Ubuntu USN / Debian Security).
  • Фильтрация невоспроизводимых CVE и подавление FP.

СИСТЕМНАЯ АРХИТЕКТУРА

Архитектор ИБ / Enterprise

Картографирование ландшафта, контроль сегментации, интеграции и соответствие регуляторным нормам:

  • Инвентаризация периметра (EASM/CAASM), выявление Shadow IT.
  • Топология remote agents через NATS JetStream mTLS без входящих портов в сегментах.
  • Интеграция с CMDB, Active Directory, CI/CD и SIEM/SOAR.
  • Оценка соответствия: PCI DSS 4.0, CIS Controls v8, ISO 27001.

CISO / Руководство ИБ

  • Контроль соблюдения SLA ремедиации и медианного MTTR.
  • Метрики Adoption и Noise: контроль качества работы команды.

APEX Architecture Contract v1

One platform, explicit owners

APEX is an integration architecture, not a shared-database monolith. The Gateway connects systems, while each owning service keeps authoritative state and safety-critical authorization.

Normative · v1.0

Architecture rules enforced in repositories

Versioned APIs/events, canonical resource references, idempotent async consumers, W3C Trace Context, ClickHouse as analytics projection only, and signed/provenanced production promotion. The normative contract and participant registry are maintained in the private platform repository.
