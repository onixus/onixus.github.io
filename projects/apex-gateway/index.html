Компонент платформы APEX

APEX Gateway — интеграция компонентов платформы безопасности

Интеграционный шлюз APEX: единый API, версионированные контракты и маршрутизация процессов между независимыми системами безопасности.

Кому подходит

Для архитекторов и команд, объединяющих управление активами, уязвимостями, сетевой защитой и Kubernetes в общие процессы.

Возможности

  • Единая точка интеграции на FastAPI
  • Версионированные HTTP API и события
  • Сквозная трассировка запросов W3C Trace Context
  • Сохранение полномочий и данных за системой-владельцем

Пример использования

Шлюз связывает действия оператора с профильными сервисами. Решения о доступе и изменении состояния принимает сервис, которому принадлежит соответствующий объект.

Как начать

Исходный код этого компонента находится в закрытом репозитории. Публичного пакета для самостоятельной установки на этой странице нет.

Ограничения и статус

Репозиторий закрыт. Публичная страница описывает назначение компонента; открытая инструкция самостоятельной установки здесь не предоставляется.
