Pulse — сканирование сети и обнаружение сервисов

Pulse: сетевой сканер на Rust для платформы APEX. Выполнение сканирований, наблюдения о сервисах, версионированный API и события отчётов.

Кому подходит

Для команд ИБ и эксплуатации, которым нужны наблюдения о доступных узлах и сервисах в разрешённом для обследования периметре.

Возможности

  • Асинхронное сканирование сети и сервисов
  • Версионированные маршруты API сканирования
  • События отчётов для интеграции с APEX
  • Проверяемый в CI контракт компонента

Пример использования

Оператор задаёт область обследования. Pulse выполняет сканирование и передаёт наблюдения потребителям через API и контракт событий.

Как начать

Исходный код этого компонента находится в закрытом репозитории. Публичного пакета для самостоятельной установки на этой странице нет.

Ограничения и статус

Репозиторий закрыт, публичная загрузка отсутствует. Результаты зависят от сетевой доступности узлов и ограничений выбранного режима сканирования.
