R-TrustTunnel — VPN-клиент для TrustTunnel, Hysteria 2 и AmneziaWG

R-TrustTunnel: VPN-клиент на Rust для Windows, Linux, macOS и Android. Профили TrustTunnel, Hysteria 2 и AmneziaWG 3, диагностика и восстановление.

Кому подходит

Для пользователей и администраторов собственных VPN-серверов, которым нужен клиент с управлением профилями и диагностикой соединения.

Возможности

  • TrustTunnel по HTTP/2 и HTTP/3
  • Поддержка Hysteria 2 и AmneziaWG 3
  • Зашифрованное хранение и импорт профилей
  • Диагностика, восстановление подключения и защита fail-closed

Пример использования

Пользователь получает профиль своего сервера, импортирует его в клиент и проверяет соединение по результатам диагностики. Для управляемых профилей предусмотрена синхронизация с порталом.
